# デッキの運用方針

関連するテーマをAnkiの親デッキにまとめ、地域・季節、その下に学習方向を置きます。全体を学習するときは親デッキを選びます。全体版と地域別・季節別で同じ問題を重複して収録せず、「スターター」という表示名も使いません。階層の一覧と移行手順は [README.md](../README.md) を参照してください。

通常方向と逆方向のカードは同じ項目の下に分け、必要な方向を選べるようにします。国旗・星図・自然物の画像問題は一方向です。ソースのディレクトリ名と既存の地域別・季節別ノートの識別子は維持します。

## 世界遺産

世界遺産は `世界遺産` を親にして、次の2デッキに分けています。

- `world-heritage-identify`: `手がかり→名称`。手がかりから世界遺産名を答える
- `world-heritage-attributes`: `名称→登録情報`。世界遺産名から登録年・区分・登録基準を確認する

UNESCOの公式データから1,273件を生成しています。将来の更新に備え、取得元のレコードを `data/sites.tsv` に保存し、1つの世界遺産から名称問題と登録情報問題を生成できるデータ構造にしています。日本語名が用意できている項目は `data/name_ja.tsv` で管理し、それ以外はUNESCOの英語名を使います。

## ビジュアルデッキ

魚介、植物、花、きのこは `生き物` を親デッキにまとめます。画像を表面に表示し、裏面に名称・学名・参照元を表示する形式で、現在は各15件です。項目リストは各テーマの `data/species.tsv` に分けています。

魚介の刺身写真は、魚体の写真とは問題の性質が異なるため、魚介デッキとは別の小規模なビジュアルデッキにします。刺身素材は今回の試作には含めず、今後追加します。

次のテーマは項目数を増やす可能性が高いものとして扱います。

- 魚介ビジュアル
- 刺身ビジュアル
- 植物ビジュアル
- 花ビジュアル
- きのこビジュアル

各テーマでは項目の基本情報とカードの問題文を分け、後から同じ項目に問題形式や詳細情報を追加できる構造にします。画像を使う場合は、画像ごとに出典、作者、ライセンス、元URLを `data/assets.tsv` に記録します。画像ファイル自体はGit管理から除外します。

世界遺産のデータを更新する場合は、次のコマンドを使います。

```sh
python3 scripts/fetch_world_heritage.py
```

魚介・植物・花・きのこの項目と画像マニフェストを更新する場合は、次のコマンドを使います。

```sh
python3 scripts/fetch_visual_taxa.py --all
```

そのあと、選定した画像を取得します。

```sh
python3 scripts/fetch_visual_assets.py --all
```

全デッキの再生成時に、世界遺産データ・ビジュアル項目・画像まで更新する場合は、次のコマンドを使います。

```sh
python3 scripts/build_all.py --refresh-world-heritage --refresh-visual-taxa --refresh-visual-assets
```
